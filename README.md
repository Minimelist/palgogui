## 🚀 Overview

P.ALGO (Personal Algorithm) is a production-grade application I built to automate my equity research and trading decisions. It ingests daily market data, applies a proprietary weightage model, and delivers the Top 10 qualified assets directly to my mobile device via Telegram.

**What makes P.ALGO unique:**
- **Quantifies the qualitative** – Uses a Mixture-of-Experts (MoE) LLM to parse macroeconomic trends, earnings sentiment, and regulatory news into quantifiable scores.
- **Eliminates manual analysis** – Fully automated daily pipeline replaces hours of spreadsheet work.
- **Modular & extensible** – Plugin-based architecture supports multiple screening strategies without core code changes.
- **Real-time delivery** – Pushes actionable insights directly to mobile via Telegram Bot API.
